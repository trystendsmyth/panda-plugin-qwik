Initial release: generates Qwik pattern components (`Box`, `Stack`, `VStack`, `HStack`, …) into `styled-system/jsx` for Panda CSS v2, with the same style props as Panda's React pattern components. Supports Qwik 1 and Qwik 2, every `outExtension`, `forceImportExtension` and `jsxStyleProps` mode.
